## Content boundaries

- Distinguish the new Foundry project/resource experience from classic hubs.
- A model generates; an agent combines a model, instructions, tools and runtime.
- Model deployment and publishing an agent application are different steps.
- Knowledge retrieval is not fine-tuning and does not mean the model already
  knows private enterprise content.
- Distinguish prompt and hosted agents. Check voice and individual tools
  separately rather than assigning one status to the entire brand.
- Check Foundry IQ component/API/portal availability independently.
- Identity, downstream access and network support require configuration.
- An engineering feedback loop is not automatic self-improvement.
- A human approval box is an illustrative application design unless the
  cited feature documentation establishes a specific managed capability.
- Do not quote volatile model counts, "latest" model names, prices or regional
  support without fresh primary evidence.
- The original research baseline (September 24, 2026) listed the separate
  Foundry Workflows feature for retirement on December 1, 2026. Recheck this
  before discussing that feature. A request-flow diagram is not that service.

If sources disagree, narrow the claim to the named component, API version,
portal surface and date. Label remaining uncertainty or omit the claim.
Use fictional scenarios and no live subscriptions, credentials or customer data.
